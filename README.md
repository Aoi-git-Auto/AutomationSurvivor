# AutomationSurvivor

> **バイオテロによって混乱する生田の街を守り抜け！**

## ゲーム概要
これは明治大学生田キャンパスで11月に行われる「生明祭」に向けて鋭意製作中の「ヴァンパイアサバイバー」風2Dサバイバルアクションゲームです。
<br>
プレイヤーは生田に住む学生の一人として、キャンパス内で起きた未曾有のバイオテロに立ち向かっていきます。次々と襲い掛かってくるナスの魔人、通称「ナスじろー」を自動で発動する多様なスキルを用いて討伐していきます。
<br>
<br>
**企画：Aoi-git-Auto**

## 製作経緯
はじめはUnity学習のためにフリー素材を使い、簡単な機能を実装したゲームを作成していました。学習終了後、改めてこのゲームを見直したとき、ちゃんとした一つのゲームとして完成させたい、という思いが溢れてきました。ゆえにこの製作再開に至りました。
<br>
展示の際にはオートメーション研究部GCC班の作品とともに展示させていただきます。
