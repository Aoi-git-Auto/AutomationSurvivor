# AutomationSurvivor

> **この世界で、生き残れ――**

## ゲーム概要
これは明治大学生田キャンパスで11月に行われる「生明祭」で展示する2Dローグライクゲームです。
<br>
プレイヤーは未知なる化け物の住まう星で最後の人類として次々と湧いてくる魔物を討伐していきます。
